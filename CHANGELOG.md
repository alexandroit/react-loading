# Changelog

All notable changes to `@stackline/react-loading` are documented here.

## [Unreleased]

- Replaced the removed `@stackline/loading` dependency with the maintained
  `@stackline/loading-core` package without changing the React wrapper API.
- Forced tsup's nested esbuild onto the patched release line.
- Upgraded all maintained React documentation apps to the current Vite 8
  toolchain and rebuilt the checked-in static documentation.
- Added a package-specific security policy and confidential reporting path.
- Added reproducible CI packaging and a manual npm provenance release workflow.
- Included release and security documentation in the published package.

## [19.0.1] - 2026-04-07

- Published the maintained React 19 loading wrapper.
- Added versioned demos and compatibility guidance for React 17 through React 19.
- Preserved the framework-agnostic behavior of the Stackline loading core.
